<h1 align="center">BetterBags - Treasures &bull; a BetterBags plugin</h1>
<p>Finds the treasures in your bags, and groups and highlights them in BetterBags: containers to open, lockboxes, and toys, mounts, pets, appearances and recipes you haven't collected yet.</p>
<p>Detection uses the game's own data (item classes, the toy box, mount and pet journals, the container's flags) and, where only the tooltip says it, the game's own text for that line. So it works in every language.</p>
<h2>Features</h2>
<ul>
<li><strong>Categories:</strong> one Treasures category, a category for each kind (Treasures: Containers, Treasures: Toys&hellip;), or none (highlight only). Their order and which bags show them are set in BetterBags like any other category.</li>
<li><strong>Treasures to find:</strong> choose the kinds that count. With <em>Only what I haven't collected yet</em>, toys, mounts, pets, appearances and recipes you already know are left out, so duplicates stay where you can sell or trade them.</li>
<li><strong>Highlight:</strong> a glow, a corner badge, or both, in the color you pick, still or pulsing. Lockboxes still locked and treasures above your level can be shown in grey.</li>
<li><strong>Your items:</strong> items that are always a treasure, or never one. Add them in the options (an item ID), or in chat, where Shift-clicking an item puts its link in: <code>/treasures always &lt;item&gt;</code>, <code>/treasures never &lt;item&gt;</code>, <code>/treasures remove &lt;item&gt;</code>, <code>/treasures list</code>.</li>
</ul>
<p>The options are in BetterBags' settings, under Integrations.</p>
<h2>Game versions</h2>
<p>Retail, WoW: Forever and every Classic version. A kind the game version doesn't have (no toy box, no pet journal&hellip;) isn't offered.</p>
